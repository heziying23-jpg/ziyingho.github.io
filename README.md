# 🌟 個人形象履歷網站 (Personal Portfolio & Resume)

一個融合**現代深色科技感 (Cyber Tech)**、**優雅雜誌編排風 (Editorial Magazine)** 與 **日系和風 (Japanese Wabi-sabi)** 的個人形象作品集網站。

> 製作者：何姿穎（馬偕專校 人工智慧醫療應用科 三年級學生）

---

## ✨ 核心特色

- 🎨 **三風格無縫切換**：右上角一鍵即時切換「暗色科技微光 ⚡」「高雅雜誌排版 📖」「日系和風 🌸」，由 CSS 設計變數系統驅動。
- 📱 **全響應式設計 (RWD)**：支援桌機、平板、手機極致體驗。
- 🧱 **模組化語意結構**：
  1. `Hero` 視覺首屏與關鍵指標儀表板 (Metrics Bar)
  2. `About Me` 理念自述與基本檔案速覽
  3. `Capabilities` 專業技能與工具箱
  4. `Selected Works` 代表專題庫（商業行銷分析、FHIR 數據分析儀表板）
  5. `Experience` 學習歷程與里程碑時間軸
  6. `Interests` 興趣與生活（追星、棒球、收藏雙欄展示）
  7. `Contact` 聯絡方式與社群入口
- 🚀 **靜態網站友善**：純原生 HTML5 / CSS3 / JavaScript，免除複雜建置步驟，可直接上傳至任何靜態網頁主機。

## 🌐 部署至靜態網頁主機

本網站為純靜態網站，可上傳至任何支援靜態網頁的主機（如學校提供的網頁空間、免費靜態主機等）。

### 部署步驟
1. 將整個專案資料夾（含 `index.html` 與 `assets/`）上傳至主機的網頁根目錄。
2. 確認 `index.html` 與 `assets/` 資料夾位於同一層級，以確保相對路徑正確。
3. 透過主機提供的網址即可瀏覽網站。

> 💡 若主機支援，也可直接將資料夾壓縮後上傳，再於主機後台解壓縮。
